# Dicta : le verbatim

Les mots de Dicta, à reprendre tels quels dans l'application, les courriels, le site et les documents. Lecteurs : toute personne qui écrit un texte pour Dicta.

## Le nom

Dicta. Une majuscule, jamais tout en capitales dans une phrase, jamais d'article : « Dicta rédige l'offre ».

## La phrase d'accroche

À écrire une fois l'argument unique choisi (docs/strategie/usp.md). Écartées : « Dicter la visite, recevoir l'offre. » et « Fini les offres le soir. », que les concurrents disent déjà.

## La description en une phrase

L'artisan dicte sa visite de chantier, Dicta rédige l'offre chiffrée.

## Les trois arguments

- Les données et l'IA sont hébergées en Suisse.
- La visite se dicte pièce par pièce.
- Les prix dictés sont comparés au catalogue de l'artisan.

## Le ton

- **Phrases courtes.** Une idée par phrase. Le sujet d'abord, le détail ensuite.
- **Boutons à l'infinitif.** « Se connecter », « Envoyer et créer l'offre », « Enregistrer ».
- **Vouvoiement.** Dans une phrase qui s'adresse à l'artisan : « Vous pouvez fermer l'application. »
- **Des faits, des chiffres.** « Prix dicté 26.00, catalogue 28.00 » plutôt que « Prix inhabituel ».
- **Aucun effet.** Ni point d'exclamation, ni émoticône, ni « magique », ni « en un clic ».
- **Le français d'ici.** « Courriel », « offre », montants en CHF au format suisse.

## Les formats

| Donnée | Exemple | Règle |
|---|---|---|
| Montant total | CHF 3’377.05 | CHF devant, une espace insécable, l'apostrophe courbe (’) pour les milliers, le point décimal, deux décimales. |
| Prix unitaire | 28.00 | Sans CHF dans une ligne d'offre : la devise est dite une fois, au total. |
| Quantité | 38 m² | L'unité tenue au chiffre par une espace insécable. |
| Date | 18.11.2026 | Jour, mois, année, séparés par des points. |
| Heure | 14:05 | Sur 24 heures. |
| Durée | 04:12 | Minutes et secondes. |
| Numéro d'offre | n° 3 |  |
| TVA | TVA 8.1 % | Le taux en chiffres, avec une espace insécable avant « % ». |

## Les phrases types

« En place » : le texte est déjà dans l'application. « À aligner » : l'application dit autre chose aujourd'hui. « À créer » : le texte manque.

| Situation | Texte | État |
|---|---|---|
| Écran de connexion | Connectez-vous pour dicter une visite et retrouver vos offres. | à aligner |
| Identifiants refusés | Courriel ou mot de passe incorrect. Vérifiez la saisie ou demandez un nouveau mot de passe. | à aligner |
| Conseil pendant la dictée | Pièce par pièce. Le nom de la pièce, les mesures, puis les travaux. | à créer |
| Après l'envoi de la dictée | Vous pouvez fermer l'application : un courriel vous préviendra quand l'offre sera prête. | en place |
| Prix à vérifier | Prix dicté 26.00, catalogue 28.00 | en place |
| Aucune offre encore | Aucune offre pour l'instant. Le micro, en bas, sert à dicter la visite ; la flèche importe un fichier. | à aligner |
| Sans réseau | Pas de réseau. La dictée est gardée sur le téléphone : touchez « Réessayer l'envoi » quand le réseau revient. | à aligner |
| Avant de supprimer | Supprimer cette offre ? Elle ne pourra pas être récupérée. | à aligner |
| Erreur de notre côté | L'offre n'a pas pu être créée. Votre dictée est gardée : réessayez dans un instant. | à aligner |
| Objet du courriel, offre prête | Votre offre est prête | en place |
| Objet du courriel, mot de passe oublié | Choisir un nouveau mot de passe pour Dicta | en place |
| Objet du courriel, premier accès | Votre accès à Dicta | en place |
| Signature des courriels | Dicta | à aligner |

## Écrire un message d'erreur

- Dire ce qui s'est passé, puis ce qu'il faut faire.
- Ne jamais accuser l'artisan : « incorrect », pas « vous vous êtes trompé ».
- Ne montrer ni code ni terme technique.
- Dire ce qui est gardé : une dictée perdue est la pire panne.
