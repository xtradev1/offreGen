## Limites

- Les offres inventées sont écrites par celui qui a écrit la consigne.
- Les deux vrais devis sont français, en euros. Aucune offre d'un artisan suisse.
- PDF sortis de Word ou d'Excel : seuls deux exports de Google Docs ont été lus.
- Douze paires pour le regroupement, écrites à la main : indication, pas mesure.
- Ollama sert une version quantifiée du modèle ; Infomaniak sert la version FP8. À rejouer chez Infomaniak.
