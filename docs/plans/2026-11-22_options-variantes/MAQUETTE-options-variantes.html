    Ce qui reste à trancher

    E1. Où l'artisan coche le choix du client ?

    O5 dit « cochées avant de facturer ». Le prototype les met aux deux endroits, avec le même état.

    E2. Où paraissent les options sur l'écran de l'offre ?

    E3. À l'ajout d'une ligne et dans la fenêtre d'une ligne : un choix « Dans le total · Option · Variante », et pour une variante, la ligne remplacée (la dernière du groupe, proposée). « + Variante » dans la fenêtre d'une ligne ouvre l'ajout réglé sur elle.

    E4. Le montant d'une option, avec un rabais de 5 % sur l'offre.

    Laquage des portes, 3 pièces à 140 : 420.00. Ta règle : le rabais en pourcentage vaut sur tout, options comprises. Il entre de toute façon dans « Total avec toutes les options ». La question est le montant écrit sur la ligne de l'option.

    E5. Sur l'écran de l'offre, une variante retenue : la ligne de base reste visible, montant barré, pour pouvoir revenir en arrière d'un toucher. Le document, lui, ne montre plus que la variante (point 2).

    Ce qui est réglé

    O1L'option reste hors du total. Bloc sous le total, case à cocher et montant, puis « Total avec toutes les options ».
    O2La variante sort sous la ligne qu'elle remplace, en italique, case, prix unitaire et écart. Le total compte la ligne de base.
    O3Dictée : « en option », « variante », « ou alors », « à la place de ». Une variante sans ligne de base devient une option « À vérifier ».
    O4Un toucher « Option » ou « Variante » à l'ajout ; la variante remplace la dernière ligne du même groupe, modifiable.
    O5L'artisan coche ce que le client retient, renvoie l'offre, facture ou demande un acompte en un toucher.
    O6Les modèles d'abord (fait), les options ensuite.
    22.11Rabais en pourcentage : sur tout, options comprises. Rabais en francs : le même montant. Options et variantes ensemble.
    Point 2Après le choix, sur le document : option retenue dans les lignes, variante retenue à la place de sa ligne de base, le reste dans les blocs, case vide.
    Point 3Plusieurs variantes d'une même ligne, une seule retenue.
    Point 4« Total avec toutes les options » : les options seules, sans les variantes.

    Les douze modèles suivent la même règle que le Sobre montré ici. Une facture ne porte jamais d'option ni de variante non retenue. Un prix manquant sur une option bloque l'envoi, comme sur une ligne.
