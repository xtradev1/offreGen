# Revue : douze modèles d'offre pour le bâtiment

Revue du 2026-11-20. Intensité : trois relecteurs indépendants (correction, sécurité, régression), parce que le chantier touche la couche d'accès aux données (`DepotOffres`, `DepotReglages`), surface sensible du profil. Chacun a lu le code sans connaître les conclusions des autres ; aucun n'a rendu de PDF ni lancé de test. Leurs rapports complets sont dans le scratchpad de la session (`revue-correction.md`, `revue-securite.md`, `revue-regression.md`). Les verdicts sont de moi, après vérification de chaque trouvaille dans le code ou par un rendu.

Bilan : aucun défaut bloquant ; trois majeurs, tous retenus et corrigés ; dix-sept mineurs, dont dix retenus.
