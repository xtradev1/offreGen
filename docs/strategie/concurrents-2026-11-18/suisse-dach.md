# Concurrents Suisse et pays germanophones : outils d'offres pour artisans

Lecture faite le 18.11.2026. Offerto n'est pas traité ici (autre agent).

Légende des marques :
- **[off.]** lu sur la page officielle de l'éditeur (ou sa fiche App Store) ;
- **[sec.]** source secondaire (comparatif, annuaire, presse, concurrent) ;
- **[n.t.]** non trouvé.

Limite de méthode à connaître : les pages ont été lues par un outil qui résume le contenu. Les prix cités viennent de ces lectures et reprennent la forme de la page, mais les citations ne sont pas garanties mot pour mot. Avant de citer un prix en public, ouvrir la page soi-même. Aucune note d'App Store n'a pu être lue pour Werkli, Angebotsmeister, Magic Heidi ou bexio Go.
